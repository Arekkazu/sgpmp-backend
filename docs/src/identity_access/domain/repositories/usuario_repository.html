src.identity_access.domain.repositories.usuario_repository

Puerto de persistencia del agregado Usuario (capa de dominio).

Define el contrato que la capa de aplicación usa para leer y guardar usuarios, expresado en términos del dominio: recibe y devuelve la entidad Usuario y el value object Email, nunca modelos ORM ni filas. La implementación concreta vive en infraestructura (infrastructure/repositories/usuario_repository.py) y es la única que conoce SQLAlchemy.

Este puerto vive en domain/ —y no en application/ports/— para respetar la regla de dependencias: el dominio declara lo que necesita y la infraestructura lo implementa, de modo que las flechas siempre apuntan hacia adentro (infraestructura → aplicación → dominio).
