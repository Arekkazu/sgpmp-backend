## 1. ID y título

**INC-M03-112-G55** — Envío HTTP real a M04 y fragmentación de paquetes >500 no implementados.

## 2. RF y casos

## 3. Severidad y prioridad

## 5. Descripción del problema

No hay envío HTTP de paquetes de inferencia a M04 ni partición en bloques de 500.

## 6. Descripción técnica

`MotorInferenciaStubAdapter.enviar_paquete` retorna `True` sin I/O. `ConsolidarEnviarPaqueteUseCase` hace **un** `enviar_paquete` síncrono. No existe `POST /inferencia`. `max_length=500` en telemetría/visión es RF-53, no fragmentación RF-56. Un evento → un paquete (comprobado en memoria).

## 7. Ambiente

Local, pytest 9.0.3, Python 3.13.7, `--noconftest`. Sin M04 remoto. Rama `laura` `7292096f`.

HTTP a M04; 501 registros → ≥2 bloques ≤500.
