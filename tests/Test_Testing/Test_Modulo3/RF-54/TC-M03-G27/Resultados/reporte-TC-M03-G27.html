Collection Description
Parte Postman de TC-M03-G27: TC-M03-054. Un dispositivo propio informa por heartbeat 37 datos pendientes y se consulta el estado de su buffer. Se prueban la ruta de la ficha (GET /dispositivos/{id}/buffer) y la del módulo de telemetría (GET /iot/dispositivos/{id}/buffer); la respuesta debe incluir capacidad_total, capacidad_utilizada, porcentaje_ocupacion, datos_pendientes, ultimo_timestamp_pendiente, estado_buffer (NORMAL/WARNING/CRITICO) y politica_buffer_activa. Como referencia se consulta GET /iot/dispositivos/{id}/estado (RF-60). Nota: el OpenAPI de TEST no tiene ningún endpoint de estado del buffer y el heartbeat solo informa datos_pendientes_buffer (sin capacidad).
