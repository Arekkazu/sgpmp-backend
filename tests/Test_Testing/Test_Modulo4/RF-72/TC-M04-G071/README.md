Un login Veterinario QA A antes del RUN, timeout 120 s. No se requiere Administrador en el código revisado. Descubrimiento y demás peticiones son secuenciales; una sola llamada Newman dentro del RUN ejecuta 23 peticiones en orden y crea únicamente `newman/newman-G071.json` y `.html`, saneados y derivados de esa llamada. El ejecutor evalúa HTTP, cuerpo, eco y tiempos. Siempre intenta `DELETE /test-control/runs/{run_id}` y lectura poscierre.
