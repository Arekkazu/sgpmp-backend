Diseño actualizado con el issue #976

evidencia_documental es un texto obligatorio de 1 a 500 caracteres. Sirve como referencia verificable: URL de un boletín UPRA, número de acta, número de resolución o descripción del mercado. No se adjunta un archivo.

Para la fuente ESTIMADA, justificacion_estimacion es obligatoria y debe tener al menos 50 caracteres. El texto del subcaso 18 explica por qué no se usa MERCADO_ACTIVO, por qué no se usa UPRA y qué comparables se tomaron.

RF-89 v1.1 y RFC-024 C24.5 piden HTTP 400 cuando la justificación es insuficiente. En la rama laura el caso de uso todavía lanza un error de regla de negocio, que el API publica como HTTP 422. El cambio a HTTP 400 está en el PR #1024, que sigue abierto. No se comprobó el código desplegado en TEST y no se provocó el error con un POST. Una respuesta 422 no se tomará como conforme a la ficha v1.1. El subcaso 18 preparado usa una justificación suficiente, así que su resultado esperado sigue siendo HTTP 201.
