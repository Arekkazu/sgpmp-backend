Reglas observadas en el código

La antigüedad se calcula como (hoy_usuario - fecha_vigencia).days > 365. hoy_usuario es el día calendario de la zona enviada en X-Zona-Horaria; sin esa cabecera, el día es UTC. Exactamente 365 días no entra en la condición y la validación continúa. fecha_vencimiento es opcional. Si viene informada, debe ser posterior a fecha_vigencia: igual o anterior responde FECHA_VENCIMIENTO_INVALIDA. Ambas reglas lanzan ValidationError HTTP 400 dentro de _validar, antes del INSERT y del commit. Un rechazo de estas reglas no registra PRECIO_REGISTRADO.

Hallazgos

  • QUESTION-M06-G75-01: el código también rechaza una fecha de vencimiento igual a la vigencia. El subcaso 24 solo pide el caso anterior.
  • No hay una prueba unitaria del límite de 365 días en el repositorio. La aceptación de ese límite no se comprobó contra el API porque el POST guardaría el precio.
