Contrato

POST /finanzas/costos y POST /finanzas/periodos/{id}/cierre están publicados. El Contador registra y clasifica costos y puede ejecutar el cierre. El Administrador y el Revisor Fiscal consultan el cierre. Una fecha que cae en un período CERRADO no se guarda allí: el sistema busca el primer período ABIERTO posterior y, como esa fecha no le pertenece, responde 422 PERIODO_CONTABLE_CERRADO antes del INSERT. Si no hubiera un período abierto posterior, la búsqueda podría crear uno; por eso este script no envía el costo en ese caso. Un subtipo OTRO sin naturaleza queda PENDIENTE_CLASIFICACION. GET /finanzas/periodos/{id}/prevalidacion informa COSTOS_PENDIENTE_CLASIFICACION. El POST de cierre, si hay bloqueos, responde 422 CIERRE_BLOQUEADO antes de pasar el período a EN_CIERRE. Si no hay bloqueos, el cierre sí cambia el período. Esa operación no se envía. La clasificación es POST /finanzas/costos/{id}/clasificacion y tampoco se envía.
